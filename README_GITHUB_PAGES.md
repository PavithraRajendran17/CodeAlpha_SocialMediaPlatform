# Tonogram Social Media Platform - GitHub Pages Deployment

## ⚠️ Important Notice

This is the **GitHub Pages frontend deployment** of Tonogram. 

### Current Status
- ✅ **Frontend UI**: Fully functional and deployed
- ❌ **Backend API**: Not deployed (API calls will fail)
- ⚠️ **Full Functionality**: Requires backend deployment

### What Works Here
- Complete user interface
- All navigation and UI elements
- Responsive design
- Dark/light mode toggle
- Visual demonstrations of features

### What Requires Backend
- User authentication (signup/login)
- Creating posts
- Like/unlike functionality
- Comments system
- Follow/unfollow features
- Data persistence

---

## 🚀 For Full Functionality

To experience the complete Tonogram platform with all features working:

### Option 1: Local Development
```bash
# Clone the repository
git clone https://github.com/PavithraRajendran17/CodeAlpha_SocialMediaPlatform.git
cd CodeAlpha_SocialMediaPlatform

# Follow setup instructions in SETUP.md
# This requires MongoDB and Node.js
```

### Option 2: Deploy Backend
1. Deploy the backend to Heroku, Render, or Railway
2. Update the `API_URL` in `config.js` with your backend URL
3. Commit and push the changes
